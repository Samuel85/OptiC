\# OptiC



A tool for teaching the basics of geometrical optics. It lets you set different light sources, lenses, and mirrors to show the effects of refraction and image formation. I started this project at university in the early 2000s. It contains all the errors/horrors, mistakes and bugs you could expect from a physics student after taking a course on data structures and having basic C language skills. Built originally in Dev-C++, this repository contains code more for personal reasons than for any utility. For a better experience, visit my other repository, OptiC++, built from this project and after many years of learning.
